# Historical coursework source

This directory preserves the authored earlier client/server adaptation,
cryptanalysis/report scripts, browser UI, launchers and editor configuration.
It is a source-history snapshot, not the maintained application entry point.

Use [`src/affine_lab`](../../src/affine_lab),
[`pyproject.toml`](../../pyproject.toml) and the root VS Code workspace for the
independent, runnable recruiter project. Historical scripts may refer to the
original native WSL installation and its supplied executable. The supplied third-party executable is attributed in
[the coursework archive](../../archive/coursework/THIRD_PARTY_NOTICE.md).
Actual private API configuration remains excluded. The maintained package does
not depend on it.

The authored reports are under [`docs/reports`](../../docs/reports), screenshot
evidence under [`evidence/coursework`](../../evidence/coursework), and original
saved analyses/outputs under [`reports/coursework`](../../reports/coursework).
Raw capture timestamps and source data have not been rewritten to match an
edited screenshot display date.
