What Gemini does

Gemini generates the supportive English reply. Our local code encrypts the message, sends it through loopback TCP, decrypts the reply and independently recovers the Affine key. Gemini does not perform the cryptanalysis.

The web page is a presentation interface. The assignment can also run through its terminal client. Only fresh model responses need internet and an API key; saved results need neither.

Affine key: quick explanation

The key is the pair (a, b). With A=0 … Z=25:

C = (a × P + b) mod 26
P = inverse(a) × (C − b) mod 26

There are 312 valid keys. The attack ranks candidate decryptions by English-letter frequencies, then verifies the recovered key, input and response. Different moods are analyzed separately.
